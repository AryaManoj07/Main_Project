# TMDB & IMDb Movie Data Analysis

## Project Overview

This project analyzes movie data from TMDB and IMDb to explore different aspects of movies, including ratings, popularity, genres, revenue, and other relevant factors.

## Objective

The main objective of this project is to analyze movie data and identify useful patterns and relationships between different movie attributes.

## Dataset

The project uses movie data containing information such as:

* Movie titles
* Genres
* Ratings
* Popularity
* Revenue
* Release information
* Other movie-related attributes

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis

The analysis includes data cleaning, exploration, visualization, and interpretation of the movie dataset.

The complete analysis and visualizations can be found in:

`TMDB_IMDb_Movie_Data_Analysis.ipynb`

## Key Findings

The notebook contains the detailed findings, visualizations, and conclusions obtained from the analysis.

## How to Use

1. Open `TMDB_IMDb_Movie_Data_Analysis.ipynb`.
2. Open the notebook using Jupyter Notebook or Google Colab.
3. Run the cells in order to reproduce the analysis.
